### 典型问题

#### 问题 1：Agent 不调用检索工具
- **现象**：用户输入简短关键词（如"10404"），Agent 直接回答而不检索
- **原因**：ReAct Agent 自主判断信息不足，选择直接生成回复
- **影响**：回答可能不准确，出现幻觉

#### 问题 2：回答包含警告提示
- **现象**：部分回答包含"⚠️ 本回答未经知识库检索核实..."警告
- **原因**：LLM 从历史对话中学习了这个模式，自己生成警告
- **影响**：用户体验差，不必要的提示

#### 问题 3：响应速度慢
- **现象**：平均响应时间 10-20 秒
- **原因**：使用 Sonnet 模型，推理慢；两轮 LLM 调用（工具选择 + 生成回答）
- **影响**：用户等待时间长

## 优化措施（第一轮）

### 优化 1：强制检索优先

**修改内容**：
1. 在 System Prompt 开头加入"🚨 检索优先铁律"
2. 明确要求：涉及数字、关键词、术语时，**必须先检索**
3. 禁止未检索就要求用户补充信息

**修改文件**：`backend/app/agent/prompts.py`

**预期效果**：提升检索调用率，减少幻觉

### 优化 2：禁止生成警告

**修改内容**：
1. 在 System Prompt 禁止项中加入：禁止生成免责声明、警告提示
2. 在飞书回调层加强制过滤：`answer.replace("⚠️ 本回答未经...")`
3. 清空历史对话数据库，避免 LLM 学习到旧模式

**修改文件**：
- `backend/app/agent/prompts.py`
- `backend/app/api/feishu.py`

**预期效果**：彻底消除警告提示

### 优化 3：清理历史数据

**操作**：
```bash
# 清空对话历史数据库
rm store/chat.db
touch store/chat.db
```

**原因**：旧的对话记录包含警告文字，LLM 可能模仿
